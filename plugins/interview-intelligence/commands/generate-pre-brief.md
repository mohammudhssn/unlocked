# Skill: Generate Pre-Brief

## When to Use
Before Session 1 of any DIF engagement. Run this to produce the Domain Pre-Brief — a 2-page document shared with the SME 24–48 hours before the first session.

## Context
The Domain Pre-Brief signals credibility to the SME and primes deeper conversation. It tells them: you've done the surface-level work, so the session can skip orientation and go straight to what no research has indexed.

Read the `templates/pre-brief.md` template before producing the output.

If the Brave Search MCP is active, use it to run the research queries. If it's not available, generate what you can from the domain name and any notes provided, and flag which sections need manual research.

## Instructions
1. Ask for the domain name if not already in context
2. Ask for any existing research notes the user has gathered (Layer 1 — optional)
3. Generate the following search queries and execute via Brave Search MCP:
   - "[domain] market size growth rate 2024 2025"
   - "[domain] major companies tools platforms weaknesses"
   - "[domain] venture capital investment startups 2024"
   - "[domain] regulatory constraints upcoming changes"
   - "[domain] practitioner complaints frustrations forum reddit"
   - "[domain] practitioners need wish existed"
4. Synthesize results into the pre-brief structure from `templates/pre-brief.md`
5. Write the "provocation" — one hypothesis the expert is likely to disagree with (this generates the most valuable first-session reaction)
6. Keep it under 2 pages
7. Save to `templates/pre-brief-[domain].md`

## Output
`templates/pre-brief-[domain].md` — formatted, under 2 pages, ready to send to the SME.

Note any sections that need additional manual research (mark with `[NEEDS RESEARCH]`).
